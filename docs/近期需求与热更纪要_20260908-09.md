## 4. 关键客户端坑

### 4.1 ComfortValue 除 10

- `Data/Diy/Mir3.dat` 若 **`ComfortValue=True`**：tip 把舒适 **÷10** 再格式化 `+#0` → 实测值 7 显示成 **+1**。
- **必须 `ComfortValue=False`**（v15 已带 `Data-Diy-Mir3.dat.gz`）。
- 靴子舒适写在 **ItemInfoStat.Stat = Comfort**，不是 ItemInfo 列。

### 4.2 靴子属性映射

| 中文 | 正确字段 | 勿用 |
|------|----------|------|
| 舒适 | `ItemInfoStat` → **Comfort** | — |
| 穿戴负重 / 负重能力 | **WearWeight** | ~~BagWeight~~（背包负重） |
| 腕力 | **HandWeight** | — |

靴子上的 AC/MR/BagWeight 应清掉（极品随机与表属性分开处理）。

### 4.3 鞋子极品不出 AC/MR

`Server.ini` 已调高门槛关掉鞋子极品 AC/MR（示例）：

- `ShoesAC1/2/3=999999999`，`ShoesAC11/22/33=0`
- `ShoesMR1/2/3=999999999`，`ShoesMR11/22/33=0`

HP/MP/CF/ELE 等仍可按现 ini 掉极品。改 ini 后需重启服务端。

### 4.4 tip 功能随架构回退

当前线上 tip = **v9 基线 x64**（v13/v14/v15 未重编 tip 逻辑）：

| 功能 | v11/v12（x86） | 当前 v15 x64 tip |
|------|----------------|------------------|
| 指定技能 tip 抑制（CreateMagicLabel skip） | 有（v11） | **丢失**（源码仍在仓库，未打进 x64 exe） |
| 精炼等级 tip（n/6）恢复 | 有（v11） | **丢失**（相对 v11） |
| 精炼等级 tip 橙色 | 有（v12） | **丢失** |

若要恢复上述 tip 功能：需在 **x64** 工具链重编 `Mir3.exe`/`Mir3Game.exe`（体积目标仍 4130304 量级），**禁止**再发 x86 包。Magic.Description 库清空（第四波）对无 tip UI 抑制时仍有一定效果，但与「完全不建说明 Label」不同。

## 5. VPS 部署步骤（短清单）

1. **备份** 当前 `Database/System.db`、`ClientSystem.db`、`Server.ini`、7091 热更目录。
2. 服务端目录：`git fetch` → 确认无会 stash-pop 回旧库的操作 → `git pull origin main`。
3. 核对二进制：**Server.exe=82562560**，**Library.dll=2157056**。若是 82732032 / 2166272 → 立即换回授权版（见 `2e13d21` / LICENSE 笔记）。
4. **合并** `Server.ini`：保留本机端口；确认 `ShowSafeZone=False`、`*ItemSuccessRate=40`、`ExperienceRate=1000`、`DropRate/GoldRate=100`、ShoesAC*/ShoesMR* 极品关断等。
5. 确认 Scripts + Database（含 `deploy_to_Mir3service/Database/` 若走该树）已更新。
6. 热更：将 **v15** 包五个文件覆盖到 **7091** 扁平目录（含 Diy gz）。
7. 浏览器自检 `PList.Bin` / `Mir3.exe.gz` 大小。
8. 重启 `Server.exe`；确认无「授权无效」、客户端能打开、靴子舒适显示正确（如黑皮靴 +7 而非 +1）。

# 光通《传奇3》1.45官方基准来源规则

检索日期：2026-09-04

范围：光通运营的《传奇3》1.45版本。本文定义证据和版本边界；当前仅建立基准骨架，具体来源将在 Task4 填入。

## 证据等级

来源分为三级，并在基准文件的 `sources[].level` 中标记：

1. **一级**：光通或官方运营方发布、维护的原始资料，例如官方公告、客户端/服务端随附的官方数据或可核验的官方页面。用于直接确认版本规则、物品、怪物、套装及版本时间线。
2. **二级**：可追溯到官方材料的同期资料，例如官方发布内容的完整转载、同时期的维护记录或能保留原文和出处的存档。只能证明其明确保留的内容，不能把推测当作官方结论。
3. **三级**：社区整理、玩家测试、论坛讨论或其他间接线索。用于发现检索方向和提出待核查候选，不能单独确认条目，也不能单独证明版本删除。

每个来源都要说明它能证明的类别和范围，写入 `sources[].notes`。来源记录必须有稳定的标题、非空 URL、唯一 `id`、证据等级、备注、非空 `versions` 字符串数组、非空 `categories` 字符串数组和非空 `locator`。`categories` 的值只能是 `items`、`monsters`、`sets`、`version-history`；`locator` 必须能定位正文段落、表格行或存档中的具体位置。来源的 `versions` 记录该来源明确覆盖的版本。

每个物品、怪物或套装记录都必须关联至少一个来源，且来源的 `categories` 必须包含对应类别。`confirmed-145` 必须有至少一个一级或二级来源同时覆盖对应类别和 `1.45`；三级来源不能单独确认。`uncertain-version` 可以只依赖三级来源，但仍需有对应类别来源。

`excluded-later-version` 只用于明确的后续版本证据：`introducedVersion` 必须是点分数字版本且严格大于 `1.45`，并且关联的一级或二级来源要同时提供对应类别、该后续版本和 `version-history` 证据。无法确认不等于不存在，不能用缺证据推出删除结论。

搜索结果摘要、搜索引擎片段和自动生成的摘要不能作为正文证据；正文必须能够打开并复核原始内容或其可接受的存档。

## 版本边界

基准只回答光通《传奇3》1.45 的内容。1.45 之前的资料只有在能证明仍适用于 1.45 时才可使用；1.45 之后新增、改名、迁移或规则变化的资料不能倒推为 1.45 内容。版本号、公告日期和适用范围不清楚时，条目标记为 `uncertain-version`，不能标记为已确认。

无法确认不等于不存在。缺少证据只能说明当前不能确认，不得据此建议删除或声称条目不存在。只有存在明确的后续版本证据，并且条目标记为 `excluded-later-version`、同时填写非空 `introducedVersion` 时，才可以进入“建议删除候选”；这仍是审查候选，不是未经复核的删除操作。其他状态不得伪造删除结论。

## 失效官网和网页存档

官网失效时，优先寻找官方镜像、同时期的可核验网页存档或保留原文及出处的二级资料。记录实际可访问的 URL，并在备注中说明原页面失效、存档时间和能证明的内容。仅有失效链接、无法读取正文或无法核对版本的页面不能作为确认依据；网页存档也必须保留页面标题、原始 URL 和时间线信息以便复核。

当前 `audit/mir3-145/official-reference.json` 是允许空集合的 schema 基准骨架，不代表已经完成资料搜集，也不包含假网址或假官方条目。后续填充来源和条目时，每条记录都必须关联至少一个已定义来源，并遵守上述证据规则。

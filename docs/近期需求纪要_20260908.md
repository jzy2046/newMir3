## 清单与验收标准

### 1. 道馆 NPC / 安全区动画精简
- **需求**：道馆地图取消下列相关内容：活动管理员、财叔、宠物管理员、宝石合成；安全区边缘动画取消。
- **验收**：道馆内上述 NPC/入口不可见或不可交互；宝石合成入口不可用；安全区边缘动画不再播放。

### 2. 技能书：取消指定技能说明
- **需求**：技能书界面中取消下列技能的技能说明：天怒之火、陨冰杀、电闪雷鸣、旋风墙、护身法盾、灵魂分裂、吸星大法、养生术、暗鬼阵、新传染、施毒大法、分身术、焰魔召唤术、魔焰强解术、君临步、屠龙斩、金刚之躯、快刀斩马、运气术、天雷锤、挑衅、破空斩。
- **验收**：打开技能书查看上述技能时，不再显示对应技能说明文案（列表中仍可按现有逻辑处理，以「说明取消」为准）。

### 3. 综合服务：拷贝与生锈/技能书兑换调整
- **需求**：
  - 综合服务可拷贝一份（新增/复制一个可用实例）。
  - 「生锈首饰」选项保留：生锈配饰、装备刻名、技能书兑换。
  - 技能书兑换：只需遗物；取消「击杀怪物数量」条件。
  - 兑换行调整：第一行删除鹰击；第二行删除风之守护；第三行删除狂涛涌泉；第四行删除最后抵抗；第四行兑换材料改为 **4000 遗物**；最后一行删除。
  - 前四行当前不能正常兑换，需修正；兑换说明文案同步调整。
- **验收**：拷贝后的综合服务可用；生锈菜单仅保留上述三项；技能书兑换仅耗遗物且行内容/材料/说明与上表一致；前四行可正常兑换。

### 4. 综合服务：删除多余选项并注意排版
- **需求**：删除选项：材料换术、军衔进阶、元宝经验、元宝回收、声望称号、特色称号、在线泡点；注意菜单排版。
- **验收**：上述选项不再出现；剩余菜单项排列整齐、无空洞错位。

### 5. 付费鉴定文案与价格
- **需求**：付费鉴定中「元宝」显示改为「赞助币」；价格 **100 / 次**。
- **验收**：鉴定界面与扣费提示均显示赞助币；实际扣费为 100 赞助币/次。

### 6. 综合服务 NPC 外观与坐标
- **需求**：综合服务 NPC 外观变更为寄售商外观；放到道馆坐标 **401,119**（原文「倒灌」= 道馆）。
- **验收**：道馆 (401,119) 可见寄售商外观的综合服务 NPC；原错误位置不再残留可用实例（以实际部署为准）。

### 7. 删除副本类管理员 NPC（现状注明）
- **需求**：删除：蜈蚣巢穴 / 石阁庙 / 神舰 / 赤月 / 潘夜神殿 / 潘夜石窟 / 诺玛教主 管理员。
- **现状（已做）**：此前已对相关副本管理员执行 Display=True 隐藏（CreateNPCs 跳过）；2026-09-08 曾因 VPS stash 恢复旧库再次显现，已用 	ools/Mir3HideFubenNpc 重隐（Index 含 384–389、392 等，详见 09-06 纪要）。本条纪要确认需求目标为删除/不可见，与现隐藏策略一致；若需物理删库再单独立项。
- **验收**：上述管理员在游戏中不可见、不可交互。

### 9. 删除快捷键 J / U 对话框
- **需求**：删除快捷键 **J**、**U** 对应的对话框。
- **验收**：按 J、U 不再弹出原对话框（或键位无绑定）。

### 10. D 键菜单：元宝 → 赞助币，并删地图传送项
- **需求**：
  - 「元宝换金币」→「赞助币换金币」；
  - 「元宝传送」→「赞助币传送」；
  - 所有「元宝」字样 →「赞助币」；
  - 删除 D 键里「元宝地图传送」。
- **验收**：D 键菜单无「元宝」字样、无「元宝地图传送」项；兑换/传送扣赞助币且文案一致。

### 11. 杂货铺售卖调整
- **需求**：杂货铺只售卖各种大护身符（每张使用 **500** 次，统一售价 **5000**/张）；灵魂护身符照旧；删除牛角售卖。
- **验收**：货架仅见各大护身符（单价 5000、使用次数 500）+ 原灵魂护身符；无牛角。

### 12. 非装备物品 tip/类型 UI；天罡石/地煞石类型；无分割线
- **需求**：
  - 修改除去装备外物品类型的 UI 显示（如图；**图未附 → 待图**）。
  - 天罡石 / 地煞石 类型改为与「金色栗子」同一物品类型。
  - **装备之外的物品 tip（物品说明 UI）不需要分割线**：非装备物品 tip 不应显示装备 tip 中间的那条分割线。
- **验收**：非装备 tip 样式符合约定（待图确认）且**无中部分割线**；天罡石/地煞石在类型上与金色栗子一致。

### 13. 商城 / 药店商品
- **需求**：
  - 商城增加「万年雪霜」：**100 赞助币 = 1000 个**；
  - 药店增加：金疮药(特)、魔法药(特)，价格 **550**；强效太阳水，价格 **1100**。
- **验收**：商城可购万年雪霜且价量正确；药店三药可购且标价正确。

### 14. 边境村落阿斌：首饰合成成功率
- **需求**：首饰合成初始成功率改 **40%**；新增道具「结晶石」（内管用石榴石的）额外 **+10%** 成功率。
- **验收**：无结晶石时基础成功率 40%；放入结晶石（石榴石槽位/内管）时成功率再 +10%；结晶石消耗逻辑与石榴石管一致。

### 15. 掉落调整：黑度守将 / 诺玛突击队长
- **需求**：黑度守将删除裁决之杖 / 骨玉权杖 / 无极棍掉落；诺玛突击队长增加这三件掉落，掉率 **千分之一**。
- **验收**：黑度守将掉落表无上述三杖；诺玛突击队长掉落表含上述三杖且 Chance 对应 1/1000。

### 16. 超强骷髅模型
- **需求**：超强骷髅模型改为召唤骷髅的模型。
- **验收**：超强骷髅外观与召唤骷髅一致。

# 《传奇3》1.45 数据核对清单设计

## 目标

生成一份 Markdown 核对文档，将本服正式系统数据库中的全部物品、怪物和套装，与光通《传奇3》1.45 官方原版资料逐项比较，为后续人工确认和清理提供依据。

本阶段只调查和整理，不修改数据库，也不直接删除任何记录。

## 数据范围

- 本服基准：`Database/System.db`；需要客户端展示的数据同时参考 `Database/ClientSystem.db`。
- 不将 `Data/` 下的重复数据库视为正式数据源。
- 官方基准：光通《传奇3》1.45 官方资料优先；可验证的同期资料、客户端资料或高可信社区档案作为补充。
- 对照对象：全部物品、全部怪物、套装名称及套装组成物品。

## 证据规则

证据按可信度排序：

1. 1.45 同期官方网页、官方说明或官方客户端可验证数据。
2. 有明确版本标识且内容能相互印证的资料站、攻略书或历史存档。
3. 单一社区帖子、私服资料或无法确定版本的列表，仅能标记为辅助证据，不能单独作为删除依据。

找不到可靠证据不等于确认不存在；这类记录标为“版本不确定”，而不是“确认删除”。

## 名称匹配规则

- 保留数据库原始名称，不静默改名。
- 比较时归一化繁简体、全角/半角空格、常见异体字和已证实的官方译名。
- 近似名称、同物异名或疑似错别字单独标记，不能直接判为非原版。
- 同名但属性、类别或外观编号明显不同的记录，作为独立冲突项列出。

## 输出结构

最终核对文档至少包含：

1. 调查口径、数据快照信息和来源清单。
2. 数量汇总：本服数量、官方已确认数量、匹配数量及各类异常数量。
3. 物品完整对比表。
4. 怪物完整对比表。
5. 套装对比表，包括套装组成、缺失部件及版本判断。
6. 建议删除候选清单。
7. 仍需人工确认的疑点清单。

物品和怪物表使用以下字段：

| 字段 | 含义 |
|---|---|
| 本服类别 | 物品、怪物或套装 |
| 本服数据库名称 | `System.db` 中的原始名称 |
| 官方1.45名称 | 证据支持的对应名称；没有则留空 |
| 匹配状态 | 确认保留、疑似同物异名、版本不确定、确认非1.45/建议删除 |
| 判断依据 | 版本、名称、属性、来源等简要说明 |
| 证据来源 | 可访问链接或本地证据位置 |
| 处理建议 | 保留、复核、改名候选或删除候选 |

套装表额外包含组成物品、本服缺失部件和官方组成差异。

## 安全边界

- “建议删除”只是候选结论，必须经过用户人工确认。
- 不因资料缺失自动删除记录。
- 不修改 `Database/Users.db`，避免影响账号、角色和玩家物品。
- 后续若执行清理，必须先停止服务端，并由 Git 记录正式数据库变更。
- 清理动作将作为独立任务处理，不包含在本次核对文档生成范围内。

## 验收标准

- 本服数据库中可读取的物品、怪物和套装记录均出现在对比表中，不只列异常项。
- 每条记录都有明确状态，不确定项不得伪装成确定结论。
- 所有“确认非1.45/建议删除”记录都有可复核的判断依据。
- 官方清单与本服清单能够分别查看，也能按行直接比较。
- 文档记录数据库文件的校验值或快照时间，保证日后知道核对的是哪个版本。
